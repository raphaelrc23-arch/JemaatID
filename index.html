Simpel & Praktis

Cara Kerja JemaatID

Hanya butuh tiga langkah mudah untuk menghasilkan ratusan ID Card untuk jemaat Anda.

1

Unduh Template

Download file template Excel yang telah kami sediakan di bawah.

2

Isi Data Jemaat

Masukkan nama, nomor jemaat, dan data lain sesuai kolom di Excel.

3

Unggah & Cetak

Buka aplikasi, unggah file Excel, dan ID Card siap dicetak atau dibagikan!

Langkah 1: Siapkan Data

Unduh template Excel resmi kami. Struktur kolom sudah disesuaikan agar aplikasi dapat membaca data jemaat (Nama, No Jemaat, Gol. Darah, dll) secara otomatis tanpa error.

*Ukuran file: 12KB. Kompatibel dengan MS Excel & Google Sheets.

Langkah 2: Mulai Bikin!

Sudah punya data Excel-nya? Langsung masuk ke Aplikasi Web JemaatID. Tidak perlu instalasi, langsung jalan di browser Anda. Unggah, pilih desain, dan selesai!
